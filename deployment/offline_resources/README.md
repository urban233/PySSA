# Offline Resources
This directory contains files that are needed to produce the offline
installation package.
These files are:
- WindowsTask.exe
- alma-colabfold-9-rootfs.tar (size: 21 GB)

Due to their considerable size, exceeding the limits of a GitHub repository, 
these files are excluded from the repository and must be provided separately.

One file can be downloaded using the provided links:
- alma-colabfold-9-rootfs.tar: https://w-hs.sciebo.de/s/yOQ8Qo1Uvk1eaQc

The WindowsTask.exe has to be built from source.
