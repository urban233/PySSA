# Offline Resources
This directory contains files that are needed to produce the offline
installation package.
These files are:
- WindowsCli.exe

[//]: # (- alma-colabfold-9-rootfs.tar &#40;size: 21 GB&#41;)

Due to their considerable size, exceeding the limits of a GitHub repository, 
these files are excluded from the repository and must be provided separately.

The WindowsCli.exe is part of the WindowsUtilTools that can be accessed [here](https://github.com/urban233/WindowsUtilTools).
A pre-built binary can be downloaded using this [URL](https://www.dropbox.com/scl/fi/ccdz70hl76mbib37af4ve/WindowsCli.exe?rlkey=x10v0b88sda5ntoq4eh0xk13p&st=xyzyh7dp&dl=1).
After downloading the binary (or building it from source), place it in this folder.
