Proteins section:

This section groups all standalone protein structures stored in the current project.

From here you can:

  • Expand the section to see all individual proteins.
  • Select two proteins and run Analysis to compare these with another protein.
  • Select a protein and use Image to render a viewport image.
  • Select a protein and click Export File to save it as a .pdb file.
  • Select a protein and click Delete Object to remove it from the project.
  • Click Import File in the toolbar to import a .pdb file.

⚠ CAUTION:

A protein that is still part of a protein pair cannot be deleted. Delete the protein pair first.
