Export selected sequence or protein to a file on your computer:

  1. Select one or more sequences or standalone proteins in the PySSA Objects Panel. The selection of >1 sequence or protein can be done via Ctrl+Click, Shift+Click, Ctrl+arrow keys up and down and Shift+arrow keys up and down.
  2. Click on the Export File button.
  3. Choose an output directory in the file dialog.
  4. Click Select Folder.
  5. Sequences are exported as .fasta files; proteins are exported as .pdb files.

⚠ CAUTION:

Protein pairs cannot be exported with this button. Export individual proteins from the pair instead.
