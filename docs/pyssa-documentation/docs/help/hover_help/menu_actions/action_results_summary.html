View a summary of a completed distance analysis:

  1. Select a protein pair (or a protein inside a pair) in the PySSA Objects Panel.
  2. Click on Results and Summary to open the dialog.
  3. Inspect the RMSD value and the number of aligned residues.
  4. Optional: Click on View Plots to see distance histogram, distance plot and distance table.
  5. Optional: Click on Export Data to save results as a CSV file.
