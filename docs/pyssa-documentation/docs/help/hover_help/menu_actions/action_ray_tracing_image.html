Save a high-quality ray-traced image to the disk:

  1. Load a protein structure session and arrange the viewport view.
  2. Click on Image and Ray-Tracing.
  3. Choose a save location and filename in the file dialog.
  4. Click Save.
  5. Wait for the rendering job to finish. Progress is shown in the toolbar on Running Jobs.

⚠ CAUTION:

Ray-tracing can take several minutes depending on scene complexity and your hardware.
