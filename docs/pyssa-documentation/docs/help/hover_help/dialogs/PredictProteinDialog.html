Protein Structure Prediction dialog:

  1. Review the pre-selected sequences in the sequence list.
  2. Optional: Remove sequences you do not want to include in this prediction run.
  3. Optional: Check the checkbox and click on Go for running an analysis after the prediction.
  4. Click on Start to submit the job.
  5. Wait until the prediction finishes. You can monitor progress in the toolbar (Running Jobs).
  6. Once finished, the job status switches to Finished and the predicted structure(s) appear in the PySSA Objects Panel automatically.
