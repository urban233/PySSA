Use a project from your workspace:

  1. Select a project from the list.
  2. Choose an existing project.
  3. Optional: Choose another existing project in combobox or going back to select another existing project.
  4. Select the protein under Available Proteins that you want to have in your new project.
  5. Click on Add.
  6. Optional: Choose another protein(s) under Available Proteins that you want to have in your new project. Click on Add. Repeat this until you have all proteins.
  7. Optional: If you added a wrong protein to Proteins In New Project you can select this protein and click on Remove. Repeat this until you have all the proteins you really want.
  8. Click on Create.

⚠ CAUTION:

The project name must have 20 characters or fewer. Moreover, the only characters that can be used are 0-9, a-z, A-Z, -, _.
