Run a multimer protein structure prediction:

  1. Select one or more multimer sequences (comma-separated chains) in the PySSA Objects Panel.
  2. Click on Prediction and Multimer to open the prediction dialog.
  3. Verify the pre-filled sequence list in the dialog.
  4. Click on Start to begin the calculation.
  5. Wait for the job to finish. Progress is shown in the toolbar on Running Jobs.

⚠ CAUTION:

Multimer sequences must contain a comma between chain sequences (e.g. MKABC,MKLMN). An internet connection is required.
