A protein item stores a 3D protein structure (PDB data) in the project.

What you can do with a protein:

  • Select it and click Export File to save it as a .pdb file.
  • Select it and run Analysis to compare it with another protein.
  • Select it and load it into the PyMOL Viewer. After that, modify the protein and use Image to render a viewport image.
  • Select it and click Delete Object to remove it from the project.

⚠ CAUTION:

A protein that is part of a protein pair cannot be deleted independently. Delete the protein pair first.
