This section groups all amino acid sequences stored in the current project.

From here you can:

  • Expand the section to see all individual sequences.
  • Select one or more sequences and run Prediction to generate 3D structures.
  • Select a sequence and click Export File to save it as a .fasta file.
  • Select a sequence and click Delete Object to remove it from the project.
  • Click Add Sequence in the toolbar to create a new sequence manually.
  • Click Import File in the toolbar to import a .fasta file.
