Delete the selected sequence, protein or protein pair from the current project:

  1. Select one sequence, protein or protein pair in the PySSA Objects Panel.
  2. Click on the Delete Object button.
  3. Confirm the deletion in the confirmation dialog.
  4. The selected objects are permanently removed from the project.

⚠ CAUTION:

This action cannot be undone. A standalone protein cannot be deleted while it is still part of a protein pair. Delete the protein pair first, then delete the protein.
