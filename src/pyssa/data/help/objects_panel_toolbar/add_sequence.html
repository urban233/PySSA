Add a new sequence manually to the current project:

  1. Click on the Add Sequence button.
  2. Enter the sequence name in the dialog.
  3. Enter the amino acid sequence (single-letter code) in the text field.
  4. Click on Add to save the sequence to the project.

⚠ CAUTION:

The maximum length of the sequence name is 40 characters. The only characters for the sequence name that can be used are 0-9, a-z, A-Z, -, _. Moreover, multimer sequences must contain a comma between the individual chain sequences (e.g. MKABC,MKLMN).
